# Data Act Exit Audit

Public repository for AI Venture Factory venture #003: EU Data Act / SaaS switching & data-exit evidence audit.

This MVP collects only public evidence from configured SaaS documentation, generates a conservative evidence report, and publishes it through GitHub Pages. It is not legal advice and UNKNOWN must not be interpreted as non-compliance.
