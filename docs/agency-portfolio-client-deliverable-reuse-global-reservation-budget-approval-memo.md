## Contribution break-even check

Use this only as an internal screening calculation:

```
Required incremental client engagements
= annual price ÷ buyer-approved incremental contribution per engagement
```

Round required engagements upward. Count only contribution reasonably attributable to the licensed use case. Do not use gross revenue where incremental contribution is the approved measure.
