## Break-even tests

Choose the test that matches your operating model.

### 1. Incremental contribution per client engagement

`break-even engagements = JPY 7,980,000 / incremental contribution per engagement`

| Incremental contribution per engagement | Engagements needed to cover annual price |
| ---: | ---: |
| JPY 25,000 | 320 |
| JPY 50,000 | 160 |
| JPY 100,000 | 80 |
| JPY 250,000 | 32 |

“Incremental contribution” should be calculated after delivery costs, commissions, and other variable costs. Do not use gross invoice value unless finance approves that basis.

### 2. Realizable avoided production time

`break-even hours = JPY 7,980,000 / approved fully loaded hourly cost`

| Fully loaded hourly cost | Hours needed to cover annual price |
| ---: | ---: |
| JPY 5,000 | 1,596 |
| JPY 10,000 | 798 |
| JPY 15,000 | 532 |
| JPY 20,000 | 399 |

Count only time that can realistically be removed, redeployed, or monetized. Do not count theoretical time savings that remain embedded in fixed staffing.

### 3. Combined case

`annual economic value = incremental contribution + realizable avoided cost - incremental operating cost`

`net value = annual economic value - JPY 7,980,000`

`ROI = net value / JPY 7,980,000`

A positive modeled ROI is not enough on its own. Finance should also verify cash timing, adoption risk, excluded uses, base-license eligibility, and whether the named-client band is realistic.
